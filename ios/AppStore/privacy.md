# App Privacy Answers

- Account required: No
- Advertising: No
- Tracking: No
- Third-party analytics SDK: No; consented App usage uses the first-party WebView's GA4 web connection
- Data linked to the user: None
- Data collected by the native app: Product Interaction and Other Usage Data only after the user enables “Share anonymous usage”; not linked to identity and not used for tracking
- Local-only data: app language, analytics consent, and the standard first-party WebKit cache
- Calculator inputs and results: processed client-side and explicitly excluded from analytics
- Network requests: first-party content from `https://maker.wonderelian.com/`
- External links: opened only after an explicit user action
- Privacy Nutrition Label: Usage Data → Product Interaction and Other Usage Data; not linked to the user; Analytics purpose; not used for tracking
- Non-exempt encryption: No (`ITSAppUsesNonExemptEncryption=false`)
